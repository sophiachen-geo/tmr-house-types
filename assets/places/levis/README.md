# assets/places/levis — intentionally empty

No image is published for Lévis.

The Ville de Lévis conditions d'utilisation, read on 16 August 2026 before any image was handled,
state:

> Il vous est interdit de copier ou de publier, pour rediffusion à des tiers ou à des fins
> commerciales, la moindre partie du contenu.

Republication to third parties is expressly prohibited, so none of the catalogue's photographs —
including the ANCIENNE / AVANT / POTENTIEL / APRÈS restoration sets that are unique to Lévis in this
project — is copied here. Each type record instead carries a `photos[]` entry with `file: null`,
`kind: placeholder`, `licence: "permission required"` and the fiche's `source_url`, and the full
per-image inventory with URLs is in `sources/levis/parsed.json`. See `sources/levis/MANIFEST.md` §3.

Two routes remain open for actual imagery: a permission request to the Ville de Lévis (flagged for
Part 8b), and freely-licensed Wikimedia Commons photographs of Vieux-Lévis, verified through the
Commons API.
