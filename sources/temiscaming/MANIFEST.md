# Source manifest — Témiscaming

No downloadable typology document exists for Témiscaming, so this folder holds no PDFs. The reference
sources are cited in `data/places/temiscaming/sources.yaml`:

- Canadian Centre for Architecture, "Power and Planning: Industrial Towns in Québec, 1890–1950" (1996)
  — <https://www.cca.qc.ca/en/articles/issues/11/nature-reorganized/441/power-and-planning>
- RPCQ, Gare de Témiscaming (classée 19 October 2012)
- Ville de Témiscaming, "History"; The Canadian Encyclopedia, "Témiscaming"
- MRC de Témiscamingue built-heritage inventory (launched 2023, due April 2026) — the only prospect of
  house types beyond "Type 171C". Check mrctemiscamingue.qc.ca quarterly.
