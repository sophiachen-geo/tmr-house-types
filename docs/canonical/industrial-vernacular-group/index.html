Maison vernaculaire industrielle (group — cubique, cottage vernaculaire, Boomtown)

A parent grouping, not a building shape. Québec's sources disagree about the level of this thing: the Île d'Orléans inventory and the Lévis catalogue treat cubique, cottage vernaculaire américain and Boomtown as three top-level courants, while the Charlesbourg plan de conservation and the Ville de Québec thésaurus nest all three under one parent. This id carries the parent reading so both are visible; the child forms carry the shapes.
