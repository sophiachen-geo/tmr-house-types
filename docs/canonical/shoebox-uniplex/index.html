Maison shoebox — one-storey flat-roofed rectangular house set perpendicular to the street, built to be extended upward

A single-storey flat-roofed house on a narrow rectangular plan set end-on to the street, built small and cheap by its owner and designed from the start to be built over later. The one self-built type on this site.
