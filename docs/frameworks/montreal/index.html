Framework — Ville de Montréal

The Montréal framework — Évaluation du patrimoine urbain, and the art. 120 inventory

Nine places on this site are characterised by one documentary series: the Ville de Montréal's Évaluation du patrimoine urbain, twenty-seven arrondissement cahiers researched in 2003–2004 and published in 2005. This page holds what they share — the sector code grammar, the categories, the selection criteria and the method — so that no place record has to repeat it. It also holds the statutory inventory that has since been laid over the whole island, and the one trap the series sets for anyone reading it from the outside: the number in a sector code is not the number in the filename.

Three nested scales

Montréal's residential fabric is documented at three scales, and for once they nest cleanly. Everything on the Montréal pages of this site sits at one of the three, and says which.

  • Sector scale — the Évaluation du patrimoine urbain cahiers (2005), one per arrondissement, which draw sector boundaries and grade them. This is where sectors.yaml comes from.
  • Fabric scale — the per-borough typo-morphological studies and PIIA typology annexes, which name and describe building types. This is where the type records come from: the Sud-Ouest's Patri-Arch study and Villeray–Saint-Michel–Parc-Extension's règlement 01-283-124, Annexe F.
  • Building scale — the Grand répertoire du patrimoine bâti open dataset and, since 2026, the art. 120 pre-1940 inventory. Both are address-level and neither carries a building type in a form this site can join to; see the last two sections.

The code grammar

Every sector in the series carries a code of the form [arrondissement].[letter].[n]. The cahiers state the grammar themselves, identically in each volume, in section 1.2.1:

Le système d'identification des secteurs utilisé dans le document correspond à celui des cartes. Le premier chiffre correspond au numéro d'arrondissement. Il est suivi de la lettre E pour les secteurs de valeur patrimoniale exceptionnelle, de la lettre I pour les secteurs de valeur patrimoniale intéressante, de la lettre N pour les secteurs industriels d'intérêt ou par la lettre U pour les secteurs urbains d'intérêt. Le deuxième chiffre correspond au numéro du secteur.
  • E — secteur de valeur patrimoniale exceptionnelle.
  • I — secteur de valeur patrimoniale intéressante.
  • N — secteur industriel d'intérêt (ensemble industriel d'intérêt).
  • U — secteur urbain d'intérêt (ensemble urbain d'intérêt).
  • AP — secteur d'intérêt archéologique à fort potentiel. The paragraph above names four letters; the cahiers use five. AP codes are issued from the archaeological half of the same document (section 3.2.3), researched by a different team, and they are an overlay, not a heritage ranking — a territory where the biophysical, geomorphological, archaeological and historical evidence shows a strong likelihood of buried remains, and where protective measures are required in advance of any find. On this site they carry the sector value archaeological-potential and never sit in the E/I ladder.

The code is not the filename

The cahiers are published as PDFs whose filenames begin with a two-digit number — and that number is a series number, not the arrondissement number in the codes inside. The two sequences run in different orders and collide outright. File 22_…_stla.pdf is Saint-Laurent, whose sectors are coded 8.E.n; the arrondissement that owns code 22 is Le Sud-Ouest, published as file 12_…_sud.pdf. File 27_…_wes.pdf is Westmount, coded 23; the arrondissement that owns code 27 is Mercier–Hochelaga-Maisonneuve, published as file 14_…_mercier.pdf, and file 14_… in turn is not the arrondissement coded 14, which is Villeray–Saint-Michel–Parc-Extension, published as file 26_….

The rule this site follows: read the code from inside the document, never from the filename. Every row below was verified by extracting the sector codes from the PDF text itself. A few stray codes appear in each volume where a synthesis map shows a neighbouring arrondissement's sectors bleeding across the boundary; those are map labels, not the volume's own codes, and the dominant prefix in the sector fiches is the one recorded here.

Part 11 found a third number in play, and a worse collision. The 2005 cahier prints 24.E.n beside the Ville-Marie sector names, while the 2016 Plan d'urbanisme patrimoine sheet heads its list « 25 Arrondissement de Ville-Marie ». That sheet prints no sector codes at all, so its 25 is a document number of the same series as the filename rather than a sector prefix — and 25 in the 2005 sector series is Le Plateau-Mont-Royal (file 11, 25.E.1–25.E.15). So the number one Ville document gives this borough is, in another Ville document, the borough next door's. The codes table therefore carries code_2005 and code_2016 as separate columns, with the 2005 number rendered as primary because it is the one printed beside the sector names.

Part 11 added six more volumes to this table and with them the sharpest illustration of why the filename cannot be trusted: file 19 is Pointe-Claire, whose sectors are coded 5, while the arrondissement that owns code 19 is Lachine, published as file 09. The two numbers 19 name different places depending on which end of the document you read. The widest gap in the whole series is Pierrefonds–Senneville, file 18 against code 2; the only volume where prefix and code agree is Dorval, 07 and 7.

The categories, and why their letters move

Section 3.2.2 of each cahier, Le cadre bâti d'intérêt patrimonial, presents its results under lettered headings. The categories are stable across the series; the letters are not. Each volume letters only the categories that its own territory contains, so C is ensembles urbains d'intérêt in the Sud-Ouest, Ville-Marie, Mercier–Hochelaga-Maisonneuve and Rosemont cahiers, but D is immeubles de valeur patrimoniale exceptionnelle in Verdun and Saint-Laurent, and Outremont's D is éléments particuliers du paysage, a category no other volume here uses. Cite the category, not the letter.

  • Les secteurs de valeur patrimoniale exceptionnelle — code letter E.
  • Les secteurs de valeur patrimoniale intéressante — code letter I.
  • Les ensembles urbains d'intérêt — code letter U.
  • Les ensembles industriels d'intérêt — code letter N.
  • Les immeubles de valeur patrimoniale exceptionnelle, and in some volumes a second list of immeubles de valeur patrimoniale intéressante. These are named buildings, not sectors, and carry no code.

Two new categories the 2004 Plan d'urbanisme invented

The ensembles urbains d'intérêt and ensembles industriels d'intérêt are flagged in the cahiers under the heading Notions nouvelles — categories created for the 2004 Plan d'urbanisme rather than inherited. The urban one matters to this site because it is the first time Montréal's postwar suburbs were connected to conservation at all: it covers, in the cahiers' own list, homogeneous bungalow ensembles, sectors of houses built to the Wartime Housing Limited model, and early housing co-operatives. The series calls its own coverage of them exploratoire.

Le Plan d'urbanisme reconnaît l'intérêt de certains développements résidentiels d'après-guerre, qui composent une part importante du patrimoine des anciennes banlieues, en créant une catégorie appelée Ensembles urbains d'intérêt. On y retrouve, entre autres, des ensembles homogènes de bungalows, des secteurs de maisons qui adoptent le modèle développé par la Wartime Housing Limited ou des exemples des premières coopératives d'habitation.

The qualification criteria, verbatim

Sectors and buildings were selected on the same three criteria, set out in section 1.2.2 and drawn from the Division's own 2001 Guide de gestion des études patrimoniales, revised 2003: « leur capacité de témoigner d'un thème ou d'un événement historique; leur qualité architecturale (forme, usage, technologie constructive); leur participation à la qualité de la vie urbaine et du paysage. » Selected sectors were then qualified into the two grades — the definitions below are the cahiers' own, adapted from the City of Ottawa's 1987 Guide d'évaluation des biens culturels et des districts historiques.

Exceptionnels : secteurs ayant conservé leurs qualités au chapitre des aménagements urbains, des implantations de bâtiments, de la géographie et des paysages et qui regroupent des suites architecturales, des alignements de bâtiments d'intérêt patrimonial, des zones unifiées par une fonction ou une typologie architecturale. Les ensembles de cette catégorie ont subi relativement peu de perturbations et présentent un caractère d'harmonie formelle et fonctionnelle. De plus, ils sont souvent reconnus comme des témoins historiques importants. — Intéressants : ensembles comprenant plusieurs bâtiments et certaines caractéristiques environnementales qui présentent un intérêt patrimonial. Ce sont toutefois des ensembles dont la trame urbaine peut avoir été partiellement modifiée, qui ont pu connaître un certain nombre de perturbations et qui renferment parfois des constructions peu intégrées à l'ensemble.
  • The comparison is internal to each arrondissement, not island-wide: « Dans tous les cas, l'échelle de comparaison pour cette qualification est l'arrondissement… ce qui fait ressortir sa spécificité dans l'ensemble montréalais. » An exceptional sector in Verdun and an exceptional sector in Ville-Marie are not claims about the same threshold. Read the grades within a borough, not across them.
  • Where a sector proved to matter island-wide, the recommendation was to protect it by constitution d'un site du patrimoine, and a building by citation, both then under the Loi sur les biens culturels. The evaluation itself confers nothing.

Two methodological notes worth carrying

The series is explicitly Lynchian, and says so in its first substantive paragraph — the urban landscape is a sequence of visual experiences along a route, not a plan seen from above.

L'approche choisie pour la sélection des bâtiments et secteurs s'appuie sur le concept de paysage urbain développé par Kevin Lynch, selon lequel le territoire se découvre à partir de l'intérieur et non à vol d'oiseau (en plan), et se compose d'une succession de séquences visuelles expérimentées le long d'un parcours.
  • Boundaries are drawn at the back of the lots, not down the middle of the streets. « Ces limites ne sont donc pas arbitrairement placées au centre des rues mais bien au fond des lots afin d'englober toutes les composantes du champ visuel. » This follows from the method: if a sector is a field of view from inside it, then both sides of a street belong to it. Anyone overlaying these sectors on a cadastral or street-centreline layer will find them off by half a block, and that is the source's intent, not an error.
  • Lists and maps cannot be separated. Every exceptional building is named, but the interesting ones were too numerous to list, so only those outside a sector were named individually. A building's absence from a list is therefore not evidence about the building.

The statutory inventory — art. 120, Loi sur le patrimoine culturel

Laid over all of the above since 2021 is an obligation that has nothing to do with the 2005 series. Article 120 of the Loi sur le patrimoine culturel, as replaced by 2021, c. 10, a. 42: « Une municipalité régionale de comté doit adopter et mettre à jour périodiquement un inventaire des immeubles construits avant 1940 qui sont situés sur son territoire et qui présentent une valeur patrimoniale. » The Act's provisions came into force on 1 April 2021 (2021, c. 10, a. 143), and its transitional article 136 set the deadline: « L'inventaire visé à l'article 120 de la Loi sur le patrimoine culturel, remplacé par l'article 42 de la présente loi, doit être adopté au plus tard le 1er avril 2026. »

That deadline has now passed. Checking whether the agglomération de Montréal adopted its inventory was left as the first task on any revisit of this page; it has been done, and the answer is yes. The Ville's own page, updated 15 June 2026, states: « En tout, ce sont 34 listes d'inventaire qui ont été réalisées puis adoptées par le Conseil d'agglomération. Il y a un inventaire pour chacun des 19 arrondissements et 15 pour chacune des villes liées, ce qui représente plus de 68 500 immeubles, qu'ils soient principaux ou secondaires. » The adopted lists were published as open data on 25 March 2026 and are counted below.

Neither of the larger figures has been restated by the Ville since adoption, so both are recorded here as historical scope claims and neither is used as a count.
  • Adoption dates in the dataset run from 18 May 2023 to 26 March 2026, and the work was heavily back-loaded: 15 166 buildings adopted on 25 September 2025, 8 946 on 18 December 2025, 16 157 on 19 February 2026 and 22 770 on 26 March 2026 — six days before the deadline. Le Plateau-Mont-Royal's 12 260 buildings all fall in that last batch. 897 records across six localities carry no adoption date at all.

What listing on the inventory does, and does not, do

This needs saying plainly, because the three instruments are constantly conflated. Inventory listing is neither citation nor classement. Citation is a municipal by-law under LPC art. 127, taken on the advice of a conseil local du patrimoine. Classement is a ministerial decision under LPC art. 29, on the advice of the Conseil du patrimoine culturel du Québec. Both create a legal status attached to the building. The art. 120 inventory creates none: the Ville's own dataset says the data are « fournies à titre indicatif et n'ont donc aucune portée légale ».

What it does instead is switch on the demolition-control regime. LAU art. 148.0.1 defines immeuble patrimonial, for the purposes of the demolition chapter, as a building cited under the LPC, in a cited heritage site, « ou inscrit dans un inventaire visé au premier alinéa de l'article 120 de cette loi » — the inventory is the third door into the same definition. Art. 148.0.2 then requires every municipality to keep in force a by-law prohibiting demolition without the authorisation of a demolition committee, and to set criteria specific to an immeuble patrimonial. The Ville puts it in plainer words: inventoried buildings are « assujettis aux règlements concernant leur occupation et leur entretien et aux règlements relatifs à la démolition », applied by the borough or the ville liée. There is a transitional sting too — under 2021, c. 10, a. 138, until both a conforming demolition by-law is in force and the art. 120 inventory is adopted for a territory, that municipality had to notify the Minister ninety days before issuing any demolition permit for a pre-1940 building.

So an inventoried Rosemont shoebox is not protected in the way a cited building is. It is protected in the way that matters most to a type that is being demolished one at a time: someone has to say yes first, in public, against criteria that include its heritage value.

One provincial deadline, four local outcomes

Article 120 falls on every MRC and every agglomération in Québec at once, and this site now holds four of them. Read together they are the clearest demonstration here that a uniform statutory obligation does not produce a uniform result.

  • Montréal — 34 lists adopted by the conseil d'agglomération, 68 652 buildings, fieldwork contracted out to Architecture 49 and photography continuing to the end of 2028. A 1940–1975 pilot inventory was also run in Saint-Laurent. The largest and latest of the four.
  • Vieux-Terrebonne (Part 8) — the MRC route, arriving alongside a provincial declaration of 20 May 2026. Inventory and declaration reinforce each other on the same territory.
  • Témiscaming (Part 5) — the negative result. The MRC's 2026 inventory retained three properties on the whole territory, none of them residential. An inventory can be complied with and still find almost nothing, and that finding is itself information about the place.
  • Lévis (Part 8) — a city that already ran a live municipal catalogue of architectural styles before the obligation existed, so the inventory lands on top of an inventory. The instrument is new; the knowledge is not.

Open tasks

The dataset gives an adoption date per building but no resolution number, and the six localities with no date at all (Rivière-des-Prairies–Pointe-aux-Trembles, L'Île-Bizard–Sainte-Geneviève, Montréal-Est, Pierrefonds-Roxboro, L'Île-Dorval, Saint-Léonard — 897 records) need resolving.
  • The inventory carries no typology field — ID_IMM_INV, ADRESSE, LOCALITE, DATE_ADOPT and little else. It cannot be joined to this site's type records by form, only by address. Whether the underlying MCCQ-method examination that produced it records a building type, and whether that is ever published, is open.
  • Enumerate the I, N and U sectors for the five Part 10 boroughs. Only E sectors are encoded so far, and the counts in the table above show how much is left: 25 I-sectors in the Sud-Ouest alone.
