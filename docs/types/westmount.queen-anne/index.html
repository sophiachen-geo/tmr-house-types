Queen Anne house

The elaborate Victorian of the lower town: asymmetrical, turreted, wrapped in a porch, and built for the first generation of Westmount's professional class.

Where it comes from

Built through the 1880s on Metcalfe and Melbourne as the village became a town; the same late-Victorian eclecticism that produced Saint-Lambert's Queen Anne houses in the same decade.
